# Discord 画像一括ダウンローダー

Discord サーバーにアップロードされた画像を、Bot を使って
**全チャンネル・全スレッド（フォーラムの投稿も含む）からまとめてダウンロード** するツールです。

- どのサーバーでも使えます（Bot を招待できるサーバーなら OK）
- 画像はチャンネルごとのフォルダに分けて保存します
- 特定のチャンネル・フォーラムだけを指定することもできます
- 途中で止めても、もう一度実行すると **続きから再開** します（保存済みの画像は飛ばします）
- ファイル名は `投稿日時（日本時間）_番号_元のファイル名` なので、名前順に並べると投稿順になります

使い方は3通りあります。**迷ったら「Google ドライブ版」がおすすめ** です。

| 使い方 | 必要なもの | 保存先 |
|---|---|---|
| 🟢 **Google ドライブ版（Colab）** | Google アカウントだけ | Google ドライブ |
| ☁ GitHub 版（Actions） | GitHub アカウント | ZIP でダウンロード |
| 💻 PC 版（Windows） | Python のインストール | PC のフォルダ |

---

## 準備：Bot を用意する（どの使い方でも必要・初回だけ）

### 1. Bot を作る
1. https://discord.com/developers/applications を開いて Discord のアカウントでログイン
2. 右上の「**New Application**」→ 好きな名前を入れて作成
3. 左メニューの「**Bot**」を開く

### 2. Bot の設定（重要）
左メニュー「Bot」の画面で：
1. 下のほうにある **「MESSAGE CONTENT INTENT」を ON** にして「Save Changes」
   （これが OFF だと、Bot は画像を見ることができません）
2. 「**Reset Token**」を押し、表示された **トークン（長い文字列）** を「Copy」でコピー
   - トークンは Bot のパスワードです。**絶対に他人に見せたり、ネットに貼ったりしないでください。**
   - 表示されるのはその1回だけです。見逃したらもう一度 Reset Token を押せば新しいものが出ます。

### 3. Bot をサーバーに招待
1. 左メニュー「**OAuth2**」→「**URL Generator**」
2. 「SCOPES」で **bot** にチェック
3. 「BOT PERMISSIONS」で **View Channels** と **Read Message History** にチェック
4. 一番下にできた URL をブラウザで開き、画像を取りたいサーバーを選んで認証

> - 招待できるのは、そのサーバーの **管理者（「サーバー管理」の権限を持つ人）** だけです。
> - 鍵付き（非公開）チャンネルの画像も取りたい場合は、そのチャンネルの設定で
>   Bot（または Bot のロール）に「チャンネルを見る」「メッセージ履歴を読む」を許可してください。

## 🟢 Google ドライブ版（おすすめ）

Google の無料サービス「Colab」を使って、画像を **Google ドライブに直接保存** します。
ブラウザだけで完結し、容量も Google ドライブの空き（無料で 15GB）まで使えます。
手順はノートブックの中にも書いてあります。

### 開き方
1. このリポジトリの `colab_downloader.ipynb` をダウンロード（ファイルを開いて右上の「↓」ボタン）
2. https://colab.research.google.com/ を開き、「**ノートブックをアップロード**」でそのファイルを選ぶ
3. メニュー「ファイル」→「**ドライブにコピーを保存**」で自分のドライブに保存しておくと、次回からそこから開けます

### 初回だけ：トークンを Colab の金庫（シークレット）に登録
1. 画面左側の **🔑（鍵）アイコン** を押す
2. 「新しいシークレットを追加」→ **名前** に `DISCORD_BOT_TOKEN`、**値** にトークンを貼り付け
3. 「ノートブックからのアクセス」を **ON**

### 実行
1. 「② 設定」で、必要に応じてサーバー名・対象チャンネルなどを書き換える
   （Bot が入っているサーバーが1つだけなら、サーバー名は空欄でOK）
2. メニュー「ランタイム」→「**すべてのセルを実行**」
3. Google ドライブへのアクセス許可を求められたら「許可」
4. 完了すると、Google ドライブの **「Discord画像」フォルダ** に、サーバー名・チャンネルごとに画像が入っています

### 注意
- 実行中はブラウザのタブを閉じないでください。止まってしまっても、もう一度実行すれば続きから再開します。
- 無料版の Colab は1回あたり最長12時間程度まで動かせます。

### 👥 友人に共有する
1. 自分の Google ドライブにある `colab_downloader.ipynb` を右クリック →「**共有**」
2. 友人のメールアドレスを入れ、権限は「**閲覧者**」にして送信
   （または「リンクを知っている全員」にしてリンクを送る）
3. 友人には次のように伝えてください：
   - 開いたら、まず「ファイル」→「**ドライブにコピーを保存**」で自分用のコピーを作る
   - Bot は **自分で作る**（ノートブック冒頭の手順どおり）
   - トークンは自分の 🔑 シークレットに登録する

> - シークレットは各自専用の保管場所なので、共有しても **あなたのトークンが友人に見えることはありません**（逆も同じ）。
> - 画像は、それぞれ実行した人の Google ドライブに保存されます。
> - **あなたの Bot のトークンを友人に渡すのはやめましょう。** 家の合鍵を渡すのと同じです。

## ☁ GitHub 版（結果を ZIP で受け取る）

GitHub の「Actions」という機能を使い、GitHub のクラウド上のパソコンでダウンロードを実行します。

### 初回だけ：トークンを GitHub の金庫（Secrets）に登録
1. GitHub でこのリポジトリを開く
2. 上のタブ **「Settings」** → 左メニュー **「Secrets and variables」→「Actions」**
3. **「New repository secret」** を押す
4. Name に `DISCORD_BOT_TOKEN`、Secret に Bot のトークンを貼り付けて **「Add secret」**

### 実行する
1. 上のタブ **「Actions」** → 左の **「Discord画像ダウンロード」** を選ぶ
2. 右側の **「Run workflow」** を押し、必要ならサーバー名・対象チャンネルを入力して緑の **「Run workflow」**
3. 数分〜数十分待つ（画像の量によります）。緑のチェックが付けば完了
4. 完了した実行をクリック → 下の **「Artifacts」** にある **`discord-images`** をクリックすると ZIP でダウンロードされます

### 注意
- 結果の ZIP は初期設定で **7日間** GitHub に置かれ、その後自動で消えます（実行時に日数を変えられます）。
- 無料プランの非公開リポジトリでは、GitHub に置いておけるファイルの合計が **約500MB** までです。
  画像が多い場合は Google ドライブ版を使ってください。
- 1回の実行は最長約6時間です。
- リポジトリを公開にすると、ZIP（画像）を他人にも見られる可能性があります。**非公開のまま** 使ってください。

## 💻 PC 版（Windows）

### 準備
1. https://www.python.org/downloads/ を開き、「Download Python」ボタンからダウンロード
2. インストーラーの最初の画面で **「Add python.exe to PATH」にチェック** を入れてから「Install Now」

### 使い方
1. このリポジトリを PC の好きな場所に置く（GitHub の「Code」→「Download ZIP」で取得して展開）
2. **`run.bat` をダブルクリック**
3. 初回はメモ帳で `config.ini` が開くので、`BOT_TOKEN =` の後ろにトークンを貼り付けて上書き保存
   （Bot が複数のサーバーに入っている場合は `GUILD_NAME =` の後ろにサーバー名も書く）
4. もう一度 **`run.bat` をダブルクリック** → ダウンロードが始まります
5. 終わると、`downloads\（サーバー名）\` の中にチャンネルごとのフォルダで画像が入っています

## 設定項目の一覧（PC 版の config.ini）

| 項目 | 説明 |
|---|---|
| `BOT_TOKEN` | Bot のトークン（必須） |
| `GUILD_NAME` | 対象サーバーの名前。Bot が入っているサーバーが1つだけなら空欄でOK |
| `GUILD_ID` | サーバーID。分かる場合はこちらが確実 |
| `CHANNELS` | 対象チャンネル（空欄なら全部）。詳しくは下の「チャンネルを指定する」 |
| `OUTPUT_DIR` | 保存先フォルダ（初期値 `downloads`） |
| `INCLUDE_VIDEOS` | `true` にすると動画も保存 |

## チャンネルを指定する（全部ではなく一部だけ取りたいとき）

どの使い方でも「対象チャンネル」（`CHANNELS`）の欄に書くと、そこだけをダウンロードします。空欄なら全チャンネルです。

- **名前・ID・チャンネルのリンク** のどれでも指定できます
- **複数** ならカンマ（`,`）で区切ります　例）`水槽写真, 質問フォーラム`
- **フォーラム** や **チャンネル** を指定すると、その中の投稿・スレッドも全部対象になります
- **カテゴリ名** を指定すると、そのカテゴリに入っているチャンネルが全部対象になります
- フォーラムの中の **特定の投稿だけ** 取りたい場合は、その投稿の名前かリンクを指定します
- 頭の `#` はあってもなくてもOK、英字の大文字・小文字は区別しません

チャンネルのリンクは、Discord でチャンネル名を **右クリック →「リンクをコピー」** で取れます。
名前が見つからなかった場合は、実行画面にサーバー内のチャンネル名一覧が表示されるので、そこからコピーしてください。

### 指定の場所
| 使い方 | 書く場所 |
|---|---|
| Google ドライブ版（Colab） | ② 設定の「対象チャンネル」 |
| GitHub 版 | 「Run workflow」を押したときに出る「対象チャンネル」 |
| PC 版 | `config.ini` の `CHANNELS =` の後ろ |

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「トークンが正しくありません」 | Developer Portal で Reset Token し、貼り直す（前後に空白が入っていないか確認） |
| 画像が1枚も見つからない | 「MESSAGE CONTENT INTENT」が ON になっているか確認 |
| 一部のチャンネルが「閲覧権限がない」 | そのチャンネルで Bot に閲覧権限を与える（ボイスチャンネルなどは問題ありません） |
| 「どのサーバーか決められません」 | Bot が複数のサーバーに入っています。表示された一覧からサーバー名をコピーして「サーバー名」の欄に書く |
| 「Python が見つかりません」 | Python を「Add python.exe to PATH」にチェックして再インストール |

## 補足
- 取得対象は「メッセージに添付（アップロード）された画像」です。URL を貼っただけの外部画像は対象外です。
- 画像が多いサーバーでは時間がかかります。途中で閉じても、再実行すれば続きからになります。
- Bot が読めるのは、Bot に閲覧権限があるチャンネルだけです。
